# 先找作用，再建立形體

人閱讀 [用途與跨域知識樹](knowledge-map.html)。程式與其他 AI 讀 [同一份結構資料](knowledge-map.json)。這份資料把產品、機構、形體與定理接在一起，不把所有東西依「像什麼形狀」塞進同一類。

## 從需求向下走

1. **用途**：替誰解決什麼問題？輸入與輸出是位置、力、物質、能量還是資訊？
2. **總成**：哪些子總成共同完成它？誰提供固定宿主，誰可以移動？
3. **機構**：靠旋轉、滑動、夾持、密封、傳熱或其他關係完成？相同目的不只有一種機構。
4. **接面**：哪兩個零件在什麼面、軸或通路接合？座標、方向、單位、間隙、接觸與順序要明列。
5. **零件與特徵**：哪一塊材料承擔責任？孔、槽、承壓面、螺紋是零件的特徵；可拆零件、材料層與形體特徵不能混為一種分解。
6. **定理與模型**：挑選符合前提的規律，輸入有來源的數值，保留量綱。數學結論、實體接觸和物理性能分別取得證據。
7. **回裝與驗證**：先確認接收件，再裝入、固定、運動及拆卸。錯誤要保留位置、視角、原因、版本、修法與同條件重驗。

## 從一條規律向外擴散

以「共同軸留下轉動自由度」為例，它可用在箱蓋、櫃門、設備維修門、窗扇及筆電上蓋。但筆電可能需要保持力矩及活動排線；窗扇需要重新處理風載、腐蝕與框架接合；木櫃的螺絲接收體不是金屬攻牙孔。

因此，每個 `applications` 條目同時保留：

| 欄位 | 要回答的問題 |
|---|---|
| `industry`、`object` | 用在哪個領域的什麼物件？ |
| `transfer` | 可以沿用哪一條關係？ |
| `recompute` | 哪些輸入、尺寸、材料與工況必須重算？ |
| `reject` | 什麼情況不能直接套用？ |
| `authority` | 是作者提出的轉用例，還是已有資格證據？本版應用例屬前者。 |

## 同形，不代表同用

圓柱作為銷，重點是軸孔及保持；作為軸，重點可能是力矩、支承與端部接合；作為套筒，重點是內外配合與承壓；作為管子，還須有連續內腔、入口、出口與流體工況。只有旋轉生成公式不能完成這四種設計。

同理，渲染的粗糙度控制外觀，不等同加工粗糙度 Ra；表面顏色不能證明材料牌號。螺紋導程可描述進給，但不足以決定鎖付扭矩、預緊力或耐久。

## 機器資料怎麼讀

`functions → mechanisms → partRoles / ruleIds / applications` 是概念路線；`products → nodes.children` 是實際車輛分解；`factory.families → objectIds → objects.owner → owners` 是廠房物件與位置；`libraryParts` 是現有十二件獨立原生資產，不能把其他目錄節點冒充已入庫的合格零件。

`nodes.id`、`parentId`、`rootId` 指向既有登錄身分，名稱不是主鍵。`mechanismIds` 只存明列用途，`contextMechanismIds` 則是上層提供的閱讀脈絡。`contextNodeId` 指出脈絡來自哪個祖先。

| 狀態 | 讀法 |
|---|---|
| `EXPLICIT_COMPONENT_ROLE` | 已依此件或子總成用途明列分類；仍不代表製造認證。 |
| `ANCESTOR_CONTEXT_ONLY` | 可循祖先找到相關教材；不得聲稱此葉件具備祖先的全部功能。 |
| `EXPLICIT_FAMILY_ROLE` | 物件類別的用途；仍要讀具體宿主與尺寸。 |
| `UNCLASSIFIED` | 不能由目前名稱確認用途；留在可查的區域，不能偷偷歸為已知零件。 |

廠房分類修正採用明列的完整名稱；`originalFamily` 保留來源分類，`classificationAuthority` 說明新路由的依據。僅有材質名稱或空名稱的物件不以猜測用途結案。

`rules` 的識別碼有 `shape:` 或 `math:` 前綴，避免兩份教材中的同名 `units`、`rigid`、`load` 被混成一筆。`sourceIds` 指向同一份資料內的來源。數學前提來自教材；各產品應用與尺寸由作者另行定義，兩者不可互換權威。

## 新增一件時的最低交接

- 用途、輸入、輸出、使用情境與故障後果。
- 唯一 ID、父總成、可拆邊界、材料邊界、形體特徵。
- 接收件 ID、共同座標、單位、方向、接觸面與間隙。
- 原始及生成參考圖的來源、採用部分與退回部分。
- 組裝順序、拆卸順序、工具通路及運動範圍。
- 適用定理、前提、變數及來源；缺失值不可由外觀補填。
- 原生形體、實際視圖與讀回範圍。
- 真實缺陷、修正與重驗；不能只留下通過數。
